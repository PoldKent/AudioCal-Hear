# AudioCal Hear — code audit / auditoría técnica

**Date / Fecha:** 2026-10-30  
**Audited branch:** `main` · **Base:** v1.8.1  
**Scope:** Single-file HTML/CSS/JS, adaptive tone testing, profiles, EQ playback and imports.

## English — findings and changes

### Implemented in main

1. **EQ headroom computation:** the chain-peak estimate for the Web Audio filter cascade used to run repeatedly when switching A/B previews or EQ states. Cached it by sample rate, filter frequencies, Q values and baseline gains. Preamp still updates, but repeated identical filter configurations reuse their estimate.
2. **Disconnected audio nodes:** explicitly disconnect stale preamp/output/filter nodes when the music player is rebuilt and when leaving the page, reducing unnecessary audio graph retention.
3. **JSON import validation:** check the `app: "AudioCal Hear"` marker in addition to the existing profile array, size limit and profile normalization. This helps prevent accidentally importing unrelated JSON files. It is not protection against malicious scripts.
4. **Compatibility:** preserved the `audiocal-hear-profiles-v1` storage schema, 7/10-band reference presets, eight languages, the −24…−84 dBFS test, explicit answer controls, and Smart Tonal Balance logic.

### Review observations (follow-up recommended)

- A single self-contained HTML file has advantages for offline distribution but is harder to unit-test and maintain. In a future version, consider separating JS/CSS into source modules and generating a one-file distribution through a build step.
- String-based localization and DOM updates are broad; systematic translation completeness tests and automated keyboard/screen-reader accessibility tests would reduce regressions.
- EQ preview filtering is computed through a peaking-filter chain; matching its electrical response does **not** prove acoustic equalization or clinically accurate hearing thresholds.
- The algorithm relies on digital dBFS, not calibrated dB SPL. Bluetooth output, headphone response and noise-floor limitations still require real-device checks.
- No dependency additions or storage migrations were made.

### Validation status

GitHub source inspection confirms all three code changes are present on `main`. The HTML remains a complete standalone file and the main feature markers are present. **A complete end-to-end browser regression and tests using real Bluetooth hardware have not been performed in this audit.** Do not treat a successful GitHub Pages deployment as acoustic validation.

## Español — hallazgos y correcciones

### Implementadas en main

1. **Cálculo de margen de audio:** el estimador de pico de los filtros se recalculaba al cambiar entre vistas A/B aunque la configuración no cambiara. Ahora se reutiliza por frecuencia de muestreo, bandas, ganancias y Q.
2. **Limpieza del grafo de audio:** desconexión explícita de filtros y nodos antiguos de preamplificación/salida al reconstruir el reproductor o abandonar la página.
3. **Validación de importaciones JSON:** se comprueba el identificador `app: "AudioCal Hear"` además del límite de archivo, la estructura de perfiles y la normalización ya existentes.
4. **Compatibilidad:** se mantienen el almacenamiento local anterior, los ocho idiomas, los ecualizadores de 7 y 10 bandas, el rango −24…−84 dBFS y el módulo de equilibrio tonal.

### Mejoras posteriores recomendadas

- Separar el código de desarrollo en módulos con un proceso que siga generando HTML independiente.
- Añadir pruebas automáticas completas para traducciones, accesibilidad, perfiles, respuestas auditivas y reproducción.
- Validar el resultado perceptivo y el comportamiento Bluetooth con equipos reales; la simulación no sustituye una medición acústica.
- Evitar interpretar los dBFS como niveles de presión sonora en el oído.

### Estado de validación

Se verificó en GitHub la presencia de los cambios y la integridad estructural del archivo. **No se ejecutó una prueba integral real de navegador ni de hardware Bluetooth en esta auditoría.** El proyecto sigue siendo una herramienta experimental, no una audiometría médica.
