# Cómo colaborar con AudioCal Hear

[English](CONTRIBUTING.md) · **Español**

Gracias por ayudar a mejorar AudioCal Hear. Es un proyecto **público para consulta, pero de carácter propietario**, no un lanzamiento de software de código abierto.

## Informar de fallos y proponer mejoras

Puedes abrir un **Issue** para comunicar problemas, sugerir funciones o plantear mejoras de accesibilidad, idiomas, compatibilidad y seguridad auditiva. No publiques perfiles personales, respaldos JSON, credenciales ni datos sensibles en las incidencias.

## Propuestas de código

Las condiciones de GitHub permiten consultar y hacer *fork* de repositorios públicos dentro de la plataforma. Puedes preparar cambios en una copia, pero **abrir una Pull Request no garantiza su aceptación ni concede permisos de escritura**.

Antes de incorporar código, el responsable debe confirmar que dispone de los permisos jurídicos necesarios (por ejemplo, mediante un acuerdo escrito de contribución o una autorización equivalente). **No debe suponerse que una Pull Request transfiere los derechos de autor ni permite relicenciar sin límites el código aportado.** Los colaboradores conservan los derechos que legalmente les correspondan, salvo pacto independiente.

No envíes código, arte, traducciones o música para los que no tengas derechos. No añadas marcas de Soundcore/Anker, elementos visuales protegidos, software comercial, herramientas de seguimiento ni dependencias con licencias incompatibles sin revisión.

## Reglas de revisión

- Solo colaboradores autorizados pueden modificar directamente el repositorio.
- El responsable revisa las propuestas y decide qué cambios incorpora.
- La participación no implica permiso para redistribuir ni alojar comercialmente copias del proyecto.
- Deben conservarse las advertencias auditivas, las bandas de EQ, el procesamiento local de perfiles y la interfaz de ocho idiomas.
- Este proyecto es una ayuda de escucha para consumidores, no audiometría médica.
