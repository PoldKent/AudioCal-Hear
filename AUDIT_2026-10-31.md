# AudioCal Hear — Maintenance refactor audit / Auditoría de refactorización

**Date / Fecha:** 2026-10-31  
**Branch:** `main`  
**Application version:** 1.8.1 (no change to runtime features)  
**Result / Resultado:** Standalone build identical to original; 8/8 automated tests passed.

## English

The application was previously developed as a single HTML file. Its source has now been extracted to `src/index.template.html`, `src/styles.css`, `src/translations.json` and six logical JavaScript source modules. A no-dependency Node.js build script generates the exact same root `index.html` as before.

**Key safeguard:** the source extraction was verified by regenerating the HTML and comparing it **character for character** to the original. The new GitHub workflow subsequently confirmed `npm run check:build` and completed **8 automated unit tests with no failures**. See [workflow](https://github.com/PoldKent/AudioCal-Hear/actions/workflows/source-tests.yml).

Test coverage includes the production threshold search, floor response, contradictory confirmation, minimum level, localization, preset feature markers and music-filter peak estimation.

No new runtime dependencies, remote telemetry, storage migrations, or audio-level increases were introduced. All saved profile storage keys, equalizer standards and safety warnings remain as previously published.

**Not verified here:** Bluetooth output selection, physical acoustic dB SPL, clinical hearing accuracy, cross-browser/iOS behavior and full UI accessibility. These remain separate validation tasks. The HTML is still proprietary and publicly inspectable.

## Español

Antes la aplicación se desarrollaba en un solo archivo HTML. Ahora sus fuentes están organizadas en plantilla, CSS, JSON de idiomas y seis módulos JavaScript de desarrollo. La herramienta de Node.js recompone exactamente el **mismo HTML independiente** publicado anteriormente.

**Protección fundamental:** se comparó el resultado compilado **carácter por carácter** con el original. Después, GitHub Actions ejecutó correctamente la comprobación de compilación y **8 pruebas automáticas sin fallos**. Consulta las [pruebas](https://github.com/PoldKent/AudioCal-Hear/actions/workflows/source-tests.yml).

Las pruebas verifican búsqueda adaptativa, límites digitales, respuestas inciertas, ocho idiomas, frecuencias de los ecualizadores originales y cálculo de margen del reproductor.

No se añadieron dependencias de ejecución, seguimiento remoto ni migraciones de perfiles. Tampoco se incrementaron los niveles de prueba.

**Pendiente de validación física:** Bluetooth real, sonoridad acústica, precisión médica, comportamiento específico de iOS y accesibilidad integral. La app sigue siendo propietaria y el HTML público puede inspeccionarse.
