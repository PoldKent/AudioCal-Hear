# Contributing to AudioCal Hear

**English** | [Español](CONTRIBUTING.es.md)

Thank you for your interest in AudioCal Hear.

## Who can edit this repository?

Anyone may view the public project and may suggest improvements. **Only the repository owner and explicitly authorized collaborators have write access.** Please do not request direct write access merely to submit a suggestion.

## How to suggest a change

1. Open a GitHub **Issue** to report a bug, request a feature, or propose an improvement.
2. If you want to submit code, **fork** the project, make your change in your fork, and open a **Pull Request** against `main`.
3. Describe what changed, why, and how you tested it on mobile.
4. The maintainer decides whether or when to incorporate it.

## Project principles

- Maintain a self-contained mobile web app without unnecessary dependencies.
- Preserve the exact reference presets for the 7-band car stereo and 10-band headphones.
- Do not present digital dBFS as acoustic sound-pressure levels.
- Favor hearing safety: conservative tone levels, clear warnings, and no sudden playback boosts.
- Keep English and Spanish documentation aligned when updating user-visible behavior.
- Respect the confidentiality of personal hearing profiles: do not add analytics or remote profile uploads without explicit disclosure and consent.

## Important limitation

A public GitHub repository without a software license is not automatically open source. Please ask the maintainer before redistributing modified copies outside what copyright law and GitHub's terms permit.
