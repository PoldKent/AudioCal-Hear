# Contributing to AudioCal Hear

**English** · [Español](CONTRIBUTING.es.md)

Thank you for helping improve AudioCal Hear. This is a **publicly viewable, proprietary project**, not an open-source software release.

## Reporting bugs and proposing improvements

You can open an **Issue** to describe bugs, suggest improvements or discuss accessibility, localization, compatibility and audio safety. Please do not publish private hearing profiles, JSON backups, credentials or personal data in issues.

## Code submissions

GitHub's public-repository terms permit viewing and forking within the platform. You may prepare proposed changes in your fork, but **opening a pull request does not guarantee acceptance or grant you write access to this repository**.

Before any code contribution is merged, the project maintainer must confirm that the contribution is legally usable by the project (for example, through an appropriate written contributor-license agreement or other documented permission). **Do not assume that publishing a PR transfers your copyright or that the maintainer has unrestricted rights to relicense your code.** You retain rights in original contributions subject to any separate written agreement.

Contributors must not submit code, artwork, translated text or music they lack rights to provide. Do not introduce unauthorized Soundcore/Anker trademarks, copyrighted interface assets, commercial software, tracking tools or third-party license obligations without review.

## Review rules

- Only explicitly authorized collaborators can directly push changes.
- All proposed code is subject to maintainer review; the owner decides what to merge.
- No permission to redistribute or commercially rehost the project is implied by participation.
- Preserve hearing-safety messaging, original supported EQ bands, privacy-local processing and the eight-language UI.
- Treat this as a consumer listening aid, not medical audiometry.
